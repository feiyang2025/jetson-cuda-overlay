# 摄像头内参标定教程

## 概述

摄像头焦距（focal length，fl）是 openpilot 测距和车道检测的核心参数。`tools/calib/` 提供了在线和离线的内参标定工具，支持长焦（FCAM）和广角（ECAM）两个摄像头。

---

## 标定工具

| 工具 | UI 按钮 | 用途 |
|------|---------|------|
| `self_calibrator.py --scan` | FCAM Calibration | 扫描历史日志 → 计算长焦内参 |
| `self_calibrator.py --live` | FCAM Live Calibration | 实时采集数据 → 计算长焦内参 |
| `wide_calibrator.py` | Wide Calibration | 实时采集立体匹配 → 计算广角内参 |

所有工具均通过 Developer Panel 操作。

---

## 长焦内参标定（FCAM）

采用三种独立方法融合计算，相互校验以提高可靠性。

### 方法1：雷达-视觉前车距离回归

利用前向雷达测距作为真值，回归视觉测距：

```
d_vision = k × d_radar + b
```

| 结果 | 含义 |
|------|------|
| k ≈ 1.0 | fl 正确 |
| k > 1.0 | fl 偏小（视觉距离增长过快） |
| k < 1.0 | fl 偏大（视觉距离增长过慢） |
| b ≈ -1.5m | 摄像头安装位置在雷达后方约 1.5m（正常） |

### 方法2：车道宽度分类统计

按车速分类，统计视觉识别的车道宽度比例因子：

| 速度区间 | 预期车道宽 | 用途 |
|----------|-----------|------|
| ≥ 90 km/h | 3.75m（高速标准） | 比例因子 = 实测 / 预期 |
| 60–90 km/h | 3.50m（快速路） | 同上 |

比例因子偏离 1.0 反映 fl 偏差。

### 方法3：IMU-模型曲率一致性

在直线路段，IMU 推算的横摆角速度曲率应与模型输出的 `desiredCurvature` 一致。系统偏差反映内参误差。

### 权重融合

三种方法加权平均得出最终 `fl_suggested`，权重取决于各自的样本量和统计稳定性。

## 广角内参标定（Wide / ECAM）

### 原理

利用 FCAM（长焦）与 ECAM（广角）的立体视觉重叠区域：

1. ORB 特征提取 + 暴力匹配建立对应点对
2. Sampson 距离极线约束过滤外点
3. 三角化计算 3D 空间点
4. 重投影误差最小化 → 最优广角焦距

### 要求

- 需要同时采集 FCAM 和 ECAM 图像帧
- 场景中需要有足够的纹理特征
- 车静态启动和低速行驶时效果最佳

---

## 使用方式

### 离线扫描

Developer Panel → **FCAM Calibration** → 单击 **RUN**

- 自动扫描 `Path::log_root()` 下的所有 rlog 段
- 逐段处理数据，融合计算结果
- 完成后显示 `fl_suggested` 和置信度
- 适合已有大量行车日志的场景

### 实时采集

Developer Panel → **FCAM Live Calibration** / **Wide Calibration** → **START**

- 行车时实时采集数据
- 停止计算后结果自动保存至 Params：
  - 长焦结果 → `FcamCalibResult`
  - 广角结果 → `WideCalibResult`
- 结果实时生效，可叠加多段行程的数据

## 结果解读

```json
{
  "fused": {
    "fl_current": 2520,
    "fl_suggested": 2685,
    "fl_factor": 1.0655,
    "confidence": "high",
    "total_observations": 179693
  }
}
```

| 字段 | 含义 |
|------|------|
| `fl_current` | 当前 `camera.py` 中使用的焦距 |
| `fl_suggested` | 建议值（三方法加权融合） |
| `fl_factor` | 修正系数（>1 增大 fl，<1 减小 fl） |
| `confidence` | 高/中/低（`high` / `medium` / `low`） |
| `total_observations` | 三种方法的总样本数 |

- `confidence` 为 `low` 时数据不足，需继续采集
- `high` 可直接将 `fl_suggested` 写入配置

---

## 注意事项

- 实时采集依赖 openpilot 各进程正常运行（carState / radarState / modelV2 / visionipc）
- 日志扫描通过 Python 虚拟环境 `.venv` 执行
- FCAM 与 ECAM 校准结果相互独立，各自保存和生效
- 建议多次校准取平均值，或使用多段不同路况的数据交叉验证
- 不同摄像头硬件（如更换摄像头模组）需要重新标定
- 任何标定结果如明显偏离预期（`fl_factor > 1.15` 或 `< 0.85`），建议检查摄像头安装状态
